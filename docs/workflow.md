# Study Workflow

This repository is designed to make daily learning easy to continue and easy to review later.

## Daily Workflow

1. Pick one small topic.
2. Create a new folder from `days/_template/`.
3. Rename it to `dayXX-topic-name`.
4. Write the explanation in `notes.md`.
5. Implement the main idea in `implementation.py`.
6. Add at least one runnable test in `test_implementation.py`.
7. Update the study index in `README.md`.
8. Commit the day as one clean checkpoint.

## What Good Daily Notes Look Like

- short enough to review quickly
- clear formulas and definitions
- one or two key intuitions in plain language
- one connection to larger deep learning or LLM systems

## What Good Daily Tests Look Like

- simple enough to run quickly
- focused on one behavior
- small numerical examples
- readable output for self-checking

## Commit Style

Recommended commit style:

- `add day02 logistic regression notes and tests`
- `refine day03 softmax implementation`
- `add weekly review template and roadmap`

## Growth Rule

If one topic becomes too large, keep the day folder focused and split the next idea into a new day instead of overloading a single folder.
